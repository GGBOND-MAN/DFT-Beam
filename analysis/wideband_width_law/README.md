# 宽带宽度律

`wang.py` 是从 Wang 2026 作者提供的复现 notebook 中抽出的函数
（cells 1,3,5,7：配置、信道、聚类工具、coarse/refined 估计器），未作修改。
其余脚本在其上运行，因此所有对比用的都是作者自己的实现，而非我们的复述。

| 脚本 | 内容 |
|---|---|
| `wbbias.py` | 宽带下 Wang 距离估计式的偏差（−1.7% 至 −80.2%） |
| `wbfit.py` | 用精确宽带图样拟合替代宽度公式（41.9% → 1.8%） |
| `law.py` | 结构 `W_meas = A(beta)u + B(beta)Wc` 的回归验证 |
| `law2.py` | 直接以距离为靶的评估——**口径有误**，见 THEORY.md §10.4 |
| `law3.py` | 以宽度还原为靶的评估（正确口径），留出集结果 |

推导与结论见 `analysis/THEORY.md` §10。
